# 南京地铁客流数据可视化平台

## 📊 项目简介

一个用于展示南京地铁各线路每日客流数据的可视化网站，支持数据录入、趋势分析和历史查询。

**在线访问：** https://nanjing-metro-dashboard.vercel.app

---

## ✨ 主要功能

### 1. 首页仪表盘
- 📈 总客流趋势图
- 🥧 线路客流占比饼图
- 📊 各线路详细数据表格
- 📅 今日/本月最高/平均客流统计

### 2. 线路详情
- 🚇 单线路历史趋势
- 📊 线路间对比分析
- 🎨 各线路独立配色

### 3. 历史数据
- 📋 完整数据表格
- 🔍 日期筛选
- 📤 CSV导出
- 📊 动态表头（自动适配新线路）

### 4. 快速录入 ⚡
- 📝 粘贴微博文字自动解析
- 📅 智能日期识别
- 🔢 自动提取各线路数据
- 📦 批量导入支持

### 5. 手动录入
- 🖊️ 表单方式逐条录入
- 💾 本地存储备份

```bash
python3 -m http.server 8080
```

然后访问 http://localhost:8080

## 📥 数据录入指南

### 方式一：快速录入（推荐）

1. 打开 **快速录入** 页面
2. 从南京地铁微博复制客流数据，例如：
   ```
   26-3-9#昨日客流#南京地铁3月9日客运量328.3，其中1号线70.7，2号线55.9，3号线61.1，4号线18.1，5号线35.4，7号线28.9，10号线18.8，S1号线9.9，S3号线9.9，S6号线5.4，S7号线1.5，S8号线10.6，S9号线2.1（以上单位: 万）
   ```
3. 粘贴到输入框，点击"解析数据"
4. 检查解析结果，点击"保存到数据文件"
5. 下载的JSON文件替换 `data/metro_data.json`

### 方式二：批量导入

1. 在批量导入区域，每行粘贴一条数据
2. 点击"批量解析并保存"
3. 下载合并后的数据文件
